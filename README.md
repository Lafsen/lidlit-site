# Lidlit

**Your lid, lit.** A free macOS menu bar app that controls the glowing Apple logo on your MacBook Pro lid: a steady glow, a slow breathe, or a blink when Claude, ChatGPT, email or chat needs you. Morse code messages, a schedule, and it keeps glowing with the lid closed.

- Website: https://lidlit.app
- Download: [Lidlit.dmg](https://github.com/Lafsen/lidlit-site/releases/latest/download/Lidlit.dmg) (MacBook Pro XDR with a lit logo, macOS 14+, Apple silicon)
- Support: https://lidlit.app/support/

This repository hosts the website and the releases. Not affiliated with Apple.
